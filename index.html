DeckTok

TikTok's real web client, hosted in a frameless Electron window and wrapped in a shell built for a gamepad. It drives the actual site rather than reimplementing it against a private API — so login, comments, DMs, LIVE and uploads all work, and keep working.

  • Synthetic input is injected at Chromium's own input pipeline, so the page receives events with isTrusted set. The virtual pointer and on-screen keyboard work on a React app that never knows the shell is there.
  • The overlay lives in a closed shadow root attached to <html>, outside the element React owns, so it can't be reconciled away and the page can't inspect it.
  • Steam preloads its overlay library into everything it launches; inside Chromium that lands in the zygote and breaks every renderer, which hangs Gaming Mode on an uncancellable spinner. The launcher strips that one entry from LD_PRELOAD.
  • The hint bar docks to any edge of the screen, taskbar-style — the same device sitting along the bottom of this page.

blockfall

A wave-based 3D arena shooter that is a single HTML file. Eleven biomes, nine weapons, upgrades chosen on level-up, and a boss every ten waves.

  • Bosses run multi-phase: phase two at 50% health, desperate at 20%.
  • Weapons span ball, scatter gun, orbit blades, chain bolt, boomerang, frost nova, seeker missiles, pulse and railgun.
  • Sandbox mode exposes a Gmod-style spawn menu and every game parameter.
  • Wave and endless modes, permanent class mastery between runs.

xcloudwrapper

Xbox Cloud Gaming as a real macOS application. Electron is the host and the plumbing here, not a reskin: no custom chrome around the player, no telemetry, no third-party pings.

  • One electron-builder target produces a universal binary for Apple Silicon and Intel.
  • Hardened runtime with explicit entitlements, and a smoke test in the repo.
  • URL routing is separated out and unit-tested, so the window can tell a sign-in redirect from a navigation away.

The whole path to a working Waydroid install — Android 13 — on a Steam Deck, written down because getting there once meant solving six unrelated problems in a row.

A physics sandbox in the browser. Spawn from a catalogue of forty-odd shapes — boxes, stairs, wedges, pipes, springs, spirals — grab them, stack them, and let the solver take it from there.

passwordgameautoplay

A Tampermonkey script that plays neal.fun's The Password Game by itself, from rule 1 through the win screen — on a live instance where the CAPTCHA, country, chess puzzle, colour, video length, Wordle answer and moon phase are different every run.
